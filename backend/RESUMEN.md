# Proyecto CineMax

Sistema de consola con persistencia JSON para administrar:

- Usuarios
- Peliculas
- Salas
- Funciones
- Ventas
- Detalles de venta

La estructura replica el ejemplo de `semanaXobjetos`:

- `config/` para configuracion, logs y persistencia
- `dao/` para la logica de negocio en memoria
- `modelos/` para las entidades
- `vistas/` para el menu interactivo
- `main.py` como punto de entrada
