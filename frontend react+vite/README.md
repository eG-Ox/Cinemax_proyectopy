# CINEMAX - FRONTEND

Frontend React + Vite para consumir la API REST de `Cinemax_proyectopy`.

## Instalacion

```powershell
npm install
```

## Configuracion

La URL del backend se puede configurar en `.env`:

```env
VITE_API_URL=http://localhost:8000
```

## Ejecucion

```powershell
npm run dev
```

URL por defecto:

```text
http://localhost:5173
```

Backend por defecto:

```text
http://localhost:8000
```
